## 🚀 About This Project

This is my personal portfolio website built with React and TypeScript. The site features a sleek, modern design showcasing my projects, skills, and professional journey in AI and Data Science.
## ✨ Features

- **Responsive Design**: Fully responsive layout that works seamlessly across all devices
- **Floating Navigation**: Smooth floating navigation bar for easy access
- **Project Showcase**: Detailed display of my technical projects and achievements
- **Skills Section**: Comprehensive overview of my technical skills and expertise
- **About Me**: Information about my background, education, and interests
- **Contact Form**: Interactive contact form for reaching out
- **Smooth Animations**: Engaging animations and transitions throughout

## 🛠️ Tech Stack

- **Frontend Framework**: React 18
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Build Tool**: Vite
- **Deployment**: Netlify
- **Version Control**: Git & GitHub

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/2006-2006/My-Portfolio.git
```

2. Navigate to the project directory
```bash
cd My-Portfolio
```

3. Install dependencies
```bash
npm install
```

4. Start the development server
```bash
npm run dev
```

5. Open your browser and visit `http://localhost:5173`

## 📦 Build for Production

```bash
npm run build
```

The build files will be generated in the `dist` directory.
